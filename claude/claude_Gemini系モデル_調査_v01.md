## 4. 判断

- **3.5 verbatim** — 逐語性はあるが**時刻が使えない。**ただし決め手は
  **40:47 で切れること**（§1 の 30 分上限）であって、ゼロ長・重なりではない。
  当初この文書は「被覆率が時刻の単調性を前提にしている」と書いていたが、
  **裏取りしたところ不正確だった（§5）。**ゼロ長 16・重なり 23 は、合成データで
  試した限り被覆率を壊さない。**実際の時刻がどれだけ外れているかは未測定**なので、
  「時刻が使えない」の根拠は今のところ打ち切りの一点である。
- **3.7 Flash** — 構造は優秀。ただし**言い淀みが消える**。逐語反訳には使えない。
- **議事録モードとして別枠で組み込む案がある。**ただし「**発話は編集される**」と
  明記すること。**「認識率が高い」とは書かない**（確かめていない）。

## 5. 裏取り — 被覆率は時刻の「何に」依存するか（2026-08-29 実測）

§4 の判断の土台なので確かめた。**結論: 条件付きで依存する。**
当初の「被覆率は時刻の単調性を前提にしている」という書き方は不正確だった。

### 被覆率そのものは時刻を使っていない

`Measured.coverage` は `matched / len(norm)`（`src/anchor.py:225`）。
**文字の一致率であって、時刻は入っていない。**

時刻に依存しているのは**探索範囲の切り方**のほうである。

- 窓は区間の**時刻の点の周り**で切る。まず ±5 秒、足りなければ ±30 秒、
  取りこぼしの拾い直しで ±120 秒（`anchor.py:47` / `:53` / `:60`）。
- **単調掃引 `floor`。**次の区間は直前の一致より後ろからしか探さない
  （`anchor.py:270` / `:283`）。コメント自身が「設計書 §3.1 の時刻単調性
  フィルタと同じ役目を、窓を切る側でまとめて果たしている」と書いている
  （`anchor.py:255`）。**ここが時刻の単調性を前提にしている箇所。**
- 単語側（track）の単調性は**守ってある。**`prepare()` が時刻順に並べ直し、
  終了時刻が前に戻らないよう均す（`anchor.py:158`）。崩れると二分探索が
  「静かに嘘をつく」とコメントにあり、それを防ぐ実装が入っている。

### 壊して測った（合成データ・200 区間 / 45 分相当）

| 壊し方 | 結果 |
| --- | --- |
| **ゼロ長 200 件**（長さ 0・位置は正しい） | **200/200 正しい** |
| **重なり 5 秒 / 40 秒**（前の区間の終わりより前に始まる） | どちらも **200/200 正しい** |
| **ゼロ長 12.6% + 重なり 18.1%**（3.5 verbatim の実測比率） | **200/200 正しい** |
| 時刻が全部 0（時刻なし相当） | 197/200 が誤った位置。ただし**全件が被覆率の壁(0.60)に落ちる** |
| 完全な逆転（降順） | 199/200 が**照合不能** |
| 1 区間だけ時刻が 5 分先 | 照合不能 11・誤り 10 |
| 1 区間だけ時刻が 20 分先 | 照合不能 81 |
| 1 区間だけ 5 分先 × **本文が互いに似ている** | **誤りなのに壁を越えた 128 件（被覆 0.93〜0.97）** |

### 分かったこと

**1. ゼロ長と重なりは、それ自体では被覆率を壊さない。**窓は区間の長さではなく
時刻の点の周りで切るので、長さ 0 でも窓の幅は変わらない。3.5 verbatim の
「ゼロ長 16・重なり 23」は、この経路では致命傷にならない。

**2. 効くのは「窓幅を超えて外れること」。**±30 秒（拾い直し ±120 秒）を超えて
外れると当たらなくなる。ただしその場合は**照合不能として落ちるか、被覆率の壁
(0.60、`inspection.py:39`)に落ちる**——つまり黙って通らない。

**3. 静かに誤った値を出す経路は、条件付きで存在する。**
**単調性が壊れる × 本文が互いに似ている**の組み合わせのとき。1 区間が先へ飛ぶと
`floor` がそこまで進み、後続が軒並み範囲外になる。近くの似た区間に高い被覆率で
乗ってしまい、**128 件が被覆 0.93〜0.97 で誤った時刻を返した。**
コード自身が「**1 件の誤マッチがファイル全体を壊す**」と書いている挙動
（`anchor.py:68`）が、そのまま出た形である。本文が十分に違う場合は 0 件で、
代わりに照合不能として落ちた。

**会議の音声は本文が似る**（「はい」「そうですね」「よろしくお願いします」）。
この条件は実際に起こりうる。

### この裏取りの限界

- **合成データでの測定である。実音声では測っていない。**
- 3.5 verbatim の実際の時刻が、窓幅（±30 秒 / ±120 秒）を超えて外れているか
  どうかは**測っていない**。ゼロ長と重なりの件数しか分かっていない。
- `listen_order.coverage` と `candidates.coverage` は名前が同じだが別物
  （件数の集計）で、時刻とは無関係だった。
