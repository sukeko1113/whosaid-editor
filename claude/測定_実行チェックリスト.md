# 測定 実行チェックリスト

1号機・配布版で 7 回。所要 約2時間15分（手を動かすのは20分程度）

---

## 最初に1回だけ

配布版を起動して、詳細設定を目で見る。

```
C:\dev\01\whosaid-editor\dist\WhosaidEditor\WhosaidEditor.exe
```

- モデル欄と下の注記が窮屈に見えないか
- 文字が切れていないか

問題なければ閉じて、測定1-1 へ。

**以降、7回とも配布版を使います。** `python -m src.main` は使いません。

# 測定1-1

出力先（以下 **G1** と書きます）:
```

```

### 1. キャッシュを消す

PowerShell で:
```powershell
cd C:\dev\01\whosaid-editor
.venv\Scripts\python.exe tools\clear_run_cache.py "G:\マイドライブ\2026年度\アプリ開発\26-08-01逐語反訳アプリ開発\テストデータ\測定 1（1号機 small  話者分離 ON）"
```

一覧が出たら `y`。**削除件数を見てから進む。**

```

```

### 3. 設定
- 音声: `01+02edited.wav`
- 出力先: **G1**
- モデル: **標準（速い）**
- 話者分離: **ON**
- チャンク長: **7分**

### 4. 開始 → ログの最初を見る

`処理経路: ローカル(モデル small)` が出るか。
違ったら止めて設定し直す。

### 5. 待つ（約17分）

### 6. ログを保存 → `測定1-1.txt`

### 7. Google ドライブの同期が終わるのを待つ

# 途中で止まったとき

**キャッシュを消し忘れた回**は、そのログを捨てて、消してから回し直してください。
「消すものがありません」と出たら、既に消えているので問題ありません。

**モデルが違った回**も同じです。捨てて回し直します。

**中断した回**は、ログを保存せずに捨ててください。中途半端なログを混ぜると
集計が読めなくなります。
